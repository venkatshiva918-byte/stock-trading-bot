HOW TO BUILD APK FOR ANDROID
============================

The mobile app is configured for Expo Application Services (EAS) to build standalone Android APK files.

PREREQUISITES
-------------
1. Node.js and npm installed.
2. Expo account (free) -> https://expo.dev/signup

STEPS TO BUILD APK
------------------

1. Install EAS CLI globally:
   npm install -g eas-cli

2. Login to your Expo account:
   eas login

3. Navigate to the mobile app directory:
   - If you are in the project root folder (stock_trading_ai), run:
     cd mobile_app
   - If you are outside the project folder, run:
     cd stock_trading_ai/mobile_app

4. Configure the project (if not already done):
   eas build:configure

5. Run the build command for Android (Preview Profile):
   eas build -p android --profile preview

   - The `--profile preview` flag tells EAS to build an APK (installable on any Android device) instead of an AAB (for Google Play Store).
   - Follow the prompts in the terminal.
   - Once the build is complete, EAS will provide a download link for the .apk file.

6. Download and Install:
   - Download the APK from the link provided.
   - Transfer it to your Android device via USB, Google Drive, or email.
   - Enable "Install from Unknown Sources" on your device if prompted.
   - Install and run the app.

NOTE ON LOCAL BUILD (Advanced)
------------------------------
If you prefer to build locally without using Expo's cloud service, run:
   eas build --platform android --local

This requires:
- Java JDK 11 or 17
- Android SDK
- Gradle
- Setting up environment variables (JAVA_HOME, ANDROID_HOME)

Using the cloud build (steps 1-5) is recommended as it handles the environment setup for you.

TROUBLESHOOTING BUILD FAILURES
------------------------------
If the build fails (e.g., "Gradle build failed"), try the following:

1. Check the build logs on the Expo dashboard (link provided in the error message).
   - Look for specific errors in the "Run gradlew" phase.
   - Sometimes transient network issues occur; try running the build again.

2. Ensure `app.json` has a valid `android.package` and `android.versionCode`.
   - The current code includes these, but if you modified them, ensure they are correct.

3. Ensure correct Java Version:
   - The `eas.json` file has been updated to use `image: "latest"`, which provides Java 17 (required by modern Android Gradle plugins).
   - If you modify `eas.json`, do not remove this setting.

4. Ensure Dependencies are compatible:
   - If you see `Unable to resolve module crypto` or similar, it means a library (like `axios`) is trying to use Node.js features not available on mobile.
   - We have pinned `axios` to `^0.27.2` to avoid this. Run `npm install` in the `mobile_app` folder if building locally.

5. Clear cache and rebuild:
   eas build -p android --profile preview --clear-cache
